# Project memory

**Before doing anything in this repo, read `.context/MAP.md`** — it's the token-efficient
codebase map (architecture, file map, key systems, conventions, brand tokens, current
status & open threads). Prefer it over re-exploring source; open source files only when
you need exact code.

- Session history: `.context/sessions/` (skim the most recent for in-flight context).
- Keep `.context/MAP.md` current when you change architecture, files, or key systems.
- **Ingest a session only when the user explicitly says so** (e.g. "ingest the session").
  Then add `.context/sessions/YYYY-MM-DD-<topic>.md`, update `.context/sessions/INDEX.md`,
  and refresh any stale part of `MAP.md`. See `.context/README.md` for the full protocol.
